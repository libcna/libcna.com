Play CNA Games

Runnable demonstrations of CNA capabilities across web, Android, and desktop platforms. CNA is a work in progress - demos reflect current state and will expand over time. Hosted browser builds are prebuilt binaries: the CNA revision each was compiled from is not recorded, so they demonstrate what CNA can do, not the behavior of the documented snapshot.

🚀

Web builds available now: CNA compiles to WebAssembly via Emscripten, and its WebGL 2 renderer (an EasyGL profile) is the Emscripten default. The demos below run directly in the browser from play.libcna.com, and 90 C++ ports of Microsoft’s XNA samples are playable at samples.libcna.com. Android APKs and prebuilt Windows binaries are not published yet.

📚 cna-samples (GitHub)

C++ ports of the official XNA Game Studio 4.0 sample library — a concrete measure of how much real XNA code has been migrated. The repository’s own plan (cna-samples revision 5db32e6, 3 October 2026) audits 153 entries — the size of the audit list, not 153 games. 91 are complete C++ ports, so the port of the relevant XNA 4.0 samples is practically complete; 8 relevant XNA 4.0 C# programs remain, and 54 entries are not port targets (XNA 3.x or older content, Silverlight and Windows Forms tools, Visual Basic and C++ projects, asset packs, duplicates and samples tied to retired services). The Racing Game Kit is ported in its own plan and is not hosted, because its original content is not treated as redistributable by the sample gallery (video). The counts belong to that pinned revision and to CNA next at that date; they are not a result for CNA snapshot c6dec91f and not a universal runtime result across renderers.

🌐

Playable sample gallery. 90 Release web builds (WebGL 2; five of them threaded) are published at samples.libcna.com, each run in Chrome when its port was completed — real XNA sample code running on CNA in your browser, not screenshots. One (PerformanceUtility) is marked partial. The same samples also run as unchanged original C# through CNA.NET.

Shader-driven samples are no longer blocked by .fx. An earlier revision of this page said that 23 samples could not build because CNA lacked compiled-shader support. That is no longer true: BloomSample, NormalMapping, PerPixelLighting, ShadowMapping, DistortionSample, ShatterEffect, NonPhotoRealistic, ColorReplacement, SkinningSample, CPUSkinning, CustomModelAnimation, CustomModelEffect, ShipGame and Spacewar are all marked complete, because the official Effect binaries produced by XNA’s own content build load through CNA’s compiled-effect path. What CNA still does not do is compile HLSL .fx source at run time; see Effects System. The remaining samples wait on owner decisions or are documented non-ports, not on a missing shader compiler.

🌐 Web Builds (Emscripten / WebGL 2)

CNA compiles to WebAssembly via Emscripten; the WEBGL2 renderer (an EasyGL profile, and the Emscripten default) runs on WebGL 2, and CNA also has an experimental WebGPU renderer for the browser. Full 2D and 3D rendering work in the browser today. These are prebuilt binaries hosted at play.libcna.com; each loads and responds to input when checked, but none is tied to a recorded CNA revision. CNA Craft, Mesh Craft and Wolf CNA are experimental projects in the libcnalab organisation; Black Pine and Tamagotchi CNA are no longer developed and their sources are preserved in CNA Cemetery. The simulators have their own section below.

🏠 Simulators

A family of first-person simulators built on CNA: large, explorable 3D worlds that put the framework under realistic load — streaming, lighting, weather, traffic and crowds. They are experimental projects in libcnalab, the GitHub organisation for experiments beside the main libcna organisation, and several of them are built on cna-engine. Each is evidence for its own revision and for the CNA revision it was built with, not for snapshot c6dec91f.

✅

All simulators are playable in the browser. Every simulator below has a browser build (Emscripten and CNA’s WebGL 2 renderer), and all of them are playable on play.libcna.com today.

House Simulator

Explore a furnished house from the basement to the attic and garden, with changing daylight and weather. WASD or arrow keys move, click to look around with the mouse, Shift switches between walk and run, and Esc opens Pause. The first load downloads a large asset package.

Play in Browser Source on GitHub

Car Simulator

A realistic passenger-car driving simulator in a small fictional Czech town, with traffic, weather, a day-night cycle and a helicopter.

Play in Browser Source on GitHub

Street Simulator

A procedurally generated European inner-city street with a signalised junction, traffic, pedestrians, shadows and reflections. The street is built in your browser, so the first start takes about a minute. Formerly called CNA Street.

Play in Browser Source on GitHub

Room Simulator

An explorable, furnished 3D living room with changing daylight and weather, rendered by the original C++ application through the WebGL 2 renderer. WASD moves, the arrow keys look around, 1–8 switch viewpoints and F1 shows the controls. The first load downloads about 128 MiB of models. Formerly called Living Room Simulator.

Play in Browser Source on GitHub

Island Simulator

A peaceful tropical island to walk around and swim along the shore: beaches, jungle and a fresh-water stream, a hut and a campfire, a shipwreck in the shallows, a mountain cave, a grounded helicopter and a hidden bunker.

Play in Browser Source on GitHub

Museum Simulator

A 3D museum that teaches CNA as you walk through it: ten floors and 320 exhibit rooms, each demonstrating one API, labelled as XNA 4.0 or a CNA extension, with something to click, drag or toggle.

Play in Browser Source on GitHub

School Simulator

A living, walkable school: six levels, 748 rooms, an outdoor campus and up to a few thousand simulated students and staff who follow a bell schedule of lessons, breaks, lunch waves, clubs and fire drills, while the school day runs at any speed.

Play in Browser Source on GitHub

Backrooms Simulator

A small Backrooms exploration game through deterministic, effectively unbounded rooms, storage spaces and maintenance tunnels. There is no combat, inventory or game over, and the rare wanderers are harmless.

Play in Browser Source on GitHub

Train Simulator

Ride the fictional Northern Valley Express along a 286.4 km railway: walk through a six-car electric train, take a seat and watch the landscape pass the windows, with fellow passengers and a conductor on board.

Play in Browser Source on GitHub

🖥 Desktop Builds

Desktop builds are the primary current delivery target. Linux binaries and Windows executables can be built from source following the build guide. Prebuilt binaries may be published with future releases. Clone CNA’s next branch for this snapshot, as the build guide explains.

🏃 Speedy Blupi - Port / Demo

Speedy Blupi, in its 2013 Windows Phone edition, has been decompiled, translated from C# to C++ and moved onto CNA by the OpenEggbert project (repository openeggbert/mobile-eggbert, MIT-licensed). It is a showcase of the framework's capability to support real game code, a practical test of CNA's API coverage and a demonstration of the XNA-style game loop in action. It is an independent consumer of CNA, not part of CNA or its test suite: every result below belongs to the CNA revision it was built with, not to snapshot c6dec91f.

Speedy Blupi - Desktop

Builds and runs on Linux from source, and Windows builds are documented (native, MinGW cross-build, and Direct3D through Wine or Proton). No prebuilt binaries are published, and the repository lists open issues; follow the project on GitHub for updates.

🎮 cna-examples (GitHub)

A single browsable catalogue application that demonstrates CNA's own APIs area by area — rather than porting existing XNA samples, this is purpose-built teaching material. One executable (cna_examples) presents a Home → Area → Category → Demo menu you navigate at runtime, so you can step through the API surface without rebuilding. At revision ea33c9a29 (13 September 2026) 249 demo screens are registered across 13 areas and 79 categories, every one calling a real API rather than a mock. It builds against the OPENGLES3 renderer by default, though the renderer is overridable, and a hosted WebAssembly build is available above.

📝

Broad, with a catalogue checker. An earlier revision of this page described only two populated areas and no tests. Today every area has demos, tools/check_catalog.py keeps the table, plan and registrations in agreement, and the README reports all 249 screens rendering in a headless sweep. The count moves with the repository; run ./build/cna_examples --list-demos for the authoritative list.

Input — 52 screens

Keyboard, Mouse, Gamepad, Touch and a catch-all Other group (joysticks, host sensors, haptics, device enumeration and a cross-subsystem summary).

Audio — 12 screens

SoundEffect, SoundEffectInstance, 3D audio (AudioListener/AudioEmitter with Apply3D()), DynamicSoundEffectInstance, Microphone and XACT.

Graphics — 83 screens

40 in 2D Graphics and 43 in 3D Graphics, including self-checking screens that compute their own pass/fail for volume and cube textures.

Framework, Math, Content, Media, Devices, Net and more

Game loop and components, vectors and matrices, ContentManager with the XNB and CNJ formats, Song/Video/MediaLibrary, sensors and power, network sessions and leaderboards, storage, diagnostics and avatars — the remaining areas.
