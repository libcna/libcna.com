CNA-BUG-188: Stub_Smoke needs SDL3 although the STUB renderer does not, so a STUB test build without SDL cannot configure

stub_smoke_test.cpp includes the SDL3 header unconditionally and the cna_stub_test macro links SDL3::SDL3 with no if(TARGET) guard, unlike the HEADLESS and SOFTWARE example files, so STUB with CNA_ENABLE_SDL=OFF and tests on fails at generate time.

Affected contract
Building the STUB renderer with <code>CNA_BUILD_TESTS=ON</code> (the default) and <code>CNA_ENABLE_SDL=OFF</code>

Expected behaviour

STUB "touches no SDL window/video subsystem/GPU library" (modules/renderers/stub/CMakeLists.txt), and the other SDL-free-capable renderers' example files cope with a configuration without SDL: HEADLESS links SDL3 only if(TARGET SDL3::SDL3) (X11-0090) and SOFTWARE returns early with a status message (NPV-0106).

Actual behaviour at TARGET

The cna_stub_test macro in modules/renderers/stub/examples/CMakeLists.txt links SDL3::SDL3 in both of its branches, and stub_smoke_test.cpp includes the SDL3 header, calls SDL_WasInit (check A) and casts the window handle to SDL_Window* (check B). In a CNA_ENABLE_SDL=OFF configuration with STUB selected (or in CNA_GRAPHICS_RENDERERS) and tests on, CMake stops at generate time because a ::-qualified link item names no target.

Source locations

  • modules/renderers/stub/examples/CMakeLists.txt — cna_stub_test macro links SDL3::SDL3 unconditionally
  • modules/renderers/stub/examples/stub_smoke_test.cpp — SDL3 include; checks A and B use SDL
  • modules/renderers/headless/examples/CMakeLists.txt — cna_headless_test: if(TARGET SDL3::SDL3) guard
  • modules/renderers/software/examples/CMakeLists.txt — early return when SDL3::SDL3 is absent
  • modules/renderers/stub/CMakeLists.txt — the renderer itself needs no SDL

Evidence

Checked by reading at 009d40f5; such a configuration was not configured. CMake policy CMP0028 (NEW since CMake 3.0; the project requires 3.20) makes a :: link item that is not a target a generate-time error. Checks A and B are the smoke test's only SDL uses.

Focused reproduction

# Not executed for this entry.
cmake -S . -B build -DCNA_ENABLE_SDL=OFF -DCNA_PLATFORM=X11 -DCNA_GRAPHICS_RENDERER=STUB -DCNA_BUILD_TESTS=ON

Current tests

Stub_Smoke is the only family-local STUB test. The SDL-free CI lanes in platform-ci.yml build OPENGL33;VULKAN;SOFTWARE;HEADLESS, never STUB, so the configuration is not exercised.

Regression test

Guard the SDL3 link with if(TARGET SDL3::SDL3) and the SDL checks with a define (as HEADLESS does with CNA_HEADLESS_TEST_HAS_SDL), and add STUB to one SDL-free configure lane.

Blast radius

Only configurations that build STUB with tests and without SDL. Builds with SDL, STUB builds with CNA_BUILD_TESTS=OFF, and the renderer itself are unaffected.

Workaround

Configure with CNA_BUILD_TESTS=OFF, or keep SDL enabled, when STUB is selected.
