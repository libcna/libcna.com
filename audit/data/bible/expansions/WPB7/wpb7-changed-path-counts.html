What "7,027 changed paths" counts

The 7,027 figure comes from git diff --shortstat v0.1.0-alpha.1 009d40f5 with Git's default rename detection. That count treats each detected rename as one path. For a range this large, Git skips exhaustive rename detection and prints a diff.renameLimit warning. At these two commits Git's default name-status listing contains 3,358 additions, 1,098 deletions, 2,499 modifications and 72 renames. git diff --no-renames --name-status counts every rename as a deletion plus an addition and lists 7,099 records (3,430 / 1,170 / 2,499). Both figures are correct. The first counts files as Git pairs them; the second counts paths that appeared or disappeared. A comparison with another range should use the same flag and state it.
