What "7,463 changed paths" counts

The 7,463 figure comes from git diff --shortstat v0.1.0-alpha.1 c1c316b9 with Git's default rename detection. That count treats each detected rename as one path. For a range this large, Git skips exhaustive rename detection and prints a diff.renameLimit warning. At these two commits Git's default name-status listing contains 3,212 additions, 1,483 deletions, 2,704 modifications and 64 renames. git diff --no-renames --name-status counts every rename as a deletion plus an addition and lists 7,527 records (3,276 / 1,547 / 2,704). Both figures are correct. The first counts files as Git pairs them; the second counts paths that appeared or disappeared. A comparison with another range should use the same flag and state it.
