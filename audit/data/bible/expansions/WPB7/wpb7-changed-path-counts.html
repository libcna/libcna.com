What "6,302 changed paths" counts

The 6,302 figure comes from git diff --shortstat v0.1.0 c6dec91f with Git's default rename detection. That count treats each detected rename as one path. For a range this large, Git skips exhaustive rename detection and prints a diff.renameLimit warning. At these two commits Git's default name-status listing contains 788 additions, 3,840 deletions, 1,662 modifications and 12 renames. git diff --no-renames --name-status counts every rename as a deletion plus an addition and lists 6,314 records (800 / 3,852 / 1,662). Both figures are correct. The first counts files as Git pairs them; the second counts paths that appeared or disappeared. A comparison with another range should use the same flag and state it: from v0.1.0-alpha.1 to the snapshot the same commands give 10,670 (3,489 / 4,810 / 2,329 / 42 renames) and 10,712 records.
