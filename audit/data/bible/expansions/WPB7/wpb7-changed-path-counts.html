What "7,436 changed paths" counts

The 7,436 figure comes from git diff --shortstat v0.1.0-alpha.1 b0e97bb1 with Git's default rename detection. That count treats each detected rename as one path. For a range this large, Git skips exhaustive rename detection and prints a diff.renameLimit warning. At these two commits Git's default name-status listing contains 3,435 additions, 1,428 deletions, 2,507 modifications and 66 renames. git diff --no-renames --name-status counts every rename as a deletion plus an addition and lists 7,502 records (3,501 / 1,494 / 2,507). Both figures are correct. The first counts files as Git pairs them; the second counts paths that appeared or disappeared. A comparison with another range should use the same flag and state it.
