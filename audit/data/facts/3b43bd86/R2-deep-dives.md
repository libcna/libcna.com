## CNA-side inconsistencies found (not fixed; CNA is read-only)

1. **WEBGPU `RendererFeature::MultiSampleMask`** answers `Supported` whenever a device exists
   (`WebGPURenderer.hpp`, `MultiSampleMaskSupportEXT`), but on a wgpu-native Metal adapter the renderer refuses a partial mask at
   the draw with `NotSupportedException` (`SupportsPartialMultiSampleMaskEXT()` false, `WebGPURenderer.cpp` "wgpu-native's Metal
   backend has no pipeline sample mask"). By the enum's own definition that adapter is `Restricted`.
2. **EasyGL `MultiSampleMask` without `glSampleMaski`** (GL ES 3.0, WebGL 2): `MultiSampleMaskSupportEXT()` answers `Unsupported`,
   which `RendererCapabilityProfile.hpp` defines as "the mask has no effect", but `EasyGLRenderer::ApplyBlendState` throws
   `NotSupportedException` for any mask other than all ones (SOFTWARE-110) — a refusal, not "no effect"; the cross-renderer
   test `MultiSampleMaskSupportMatchesWhatTheResolvedTargetShows` expects an Unsupported renderer to draw under mask 0.
3. **Absent vertex colour**: `StockVertexSemantics.hpp` still documents `(0, 0, 0, 1)` as the neutral value "the reference renderer
   (EasyGL) leaves such an input at" and warns that a default such as white would diverge, while `EasyGLRenderer.cpp` since
   `17cd5d3c3` (2026-10-24) sets an absent colour input to white. The deep page now states both.
4. **sharp-runtime pairing**: `DependencyVersions.cmake` accepts any sharp-runtime declaring 0.1.0, but CNA at `3b43bd86`'s
   `XmlSerializationEXT.hpp` uses `System::Xml::Serialization::detail::MakeProperty`, added on sharp-runtime `next` in `f990d074`
   (2026-10-24; 41b918c9 is an ancestor). An older checkout still declaring 0.1.0 passes the configure check and then fails to
   compile any translation unit that includes the header.
5. `plans/plan_binding.md`'s task table still carries per-task counts of an earlier inventory (pre-existing, already described on
   `reference/c-api-evidence-and-gates.html`); the gate figures moved to 633 planned without the table following.
