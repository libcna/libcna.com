CNA Documentation

Everything you need to understand, build, and develop with CNA. Documentation is growing alongside the project - contributions welcome. This hub documents development snapshot 009d40f5 (24 September 2026, branch next); pages say so where they describe something the alpha.1 tag does not contain.

💡

CNA is a work in progress. Documentation reflects the current state of the codebase and is updated as features are implemented. For the most authoritative source, consult the source code and README on GitHub — and note that the repository's default branch shows the alpha.1 tag, while this site documents the next branch (snapshot 009d40f5).

📚

Doxygen API reference: CNA does not yet have a hosted Doxygen API reference. You can generate one locally: install Doxygen and use the Doxyfile in the CNA repository root as a starting point — it is close to Doxygen's defaults, so point INPUT at the modules/*/include directories and set RECURSIVE = YES; the generated HTML lands in html/index.html under the directory you run it from. Alternatively, browse the source headers directly on GitHub. The public headers are split across modules since the module refactoring: the core framework types are under modules/core/include/Microsoft/Xna/Framework/, and the graphics, input, audio, content and other namespaces live in the sibling modules/<name>/include/ directories.
